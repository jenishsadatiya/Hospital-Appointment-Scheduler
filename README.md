\# Hospital Appointment Scheduler\
\
\## Description\
This is a Python-based application designed to help hospital staff
manage doctor appointments efficiently. It allows users to book
appointments, view schedules, and cancel visits, ensuring no
double-bookings occur.\
\
\## Features\
\* \*\*Book Appointments:\*\* Store patient details, doctor names, and
time slots.\
\* \*\*Conflict Detection:\*\* Automatically prevents booking the same
doctor twice at the same time.\
\* \*\*Management:\*\* View all appointments or filter them by date.\
\* \*\*Cancellation:\*\* Remove appointments easily.\
\
\## Tech Stack\
\* \*\*Language:\*\* Python 3\
\* \*\*Libraries:\*\* Standard Library only (No external dependencies)\
\
\## How to Run\
1. Navigate to the introduction to problem solving folder: \`cd src\`\
2. Run the application: \`python hospital.py\`
