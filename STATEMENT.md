\# Problem Statement\
\
\## The Problem\
In many small clinics and healthcare facilities, appointment scheduling
is managed manually using paper registers or simple spreadsheets. This
manual process often leads to:\
1. \*\*Double-Booking:\*\* Two patients assigned to the same doctor at
the same time.\
2. \*\*Data Loss:\*\* Physical records can be misplaced or damaged.\
3. \*\*Inefficiency:\*\* Searching for available slots takes time and
delays patient care.\
\
\## Proposed Solution\
The goal of this project is to develop a \*\*Hospital Appointment
Scheduler\*\*, a console-based Python application that digitizes the
booking process. The system will:\
\* Allow receptionists to input patient and appointment details.\
\* Automatically check for time conflicts before confirming a booking.\
\* Provide a clear view of all scheduled appointments.\
\
\## Scope\
This project focuses on the logic and data structure implementation
using Python lists and dictionaries. It serves as a foundational tool
for understanding resource management systems.
